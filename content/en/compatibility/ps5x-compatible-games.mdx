## How the List Grows

PS5X inherits compatibility from Kyty, the parent project. The mechanism is a sync, not a fork: when the desktop emulator lands a milestone — a new system call translated, a graphics API path fixed — the Xbox port folds that progress in on its next update. The practical consequence for this list: it moves in steps, not a steady crawl. Expect bursts of new verified titles after each sync, followed by quiet weeks while the next milestone is chased.

That cadence mirrors exactly how the desktop scene behaved one step ahead: homebrew first, then a vanguard of lighter commercial engines, then the mid-weight titles that make up any platform's long tail. The games that boot first are always the ones that lean least on the console's exotic features — which is why a retro-styled trilogy leads a table no AAA open world appears in yet.

## What "Boots" Means in Practice

The status column deserves honesty. A game marked as booting on PS5X today means: it loads past the title screen and into gameplay on Xbox Series X hardware. It does not mean full speed, stable audio, working saves or a complete playthrough. Frame pacing is the most common rough edge; audio arriving late or dropped is second. The gap between "boots" and "playable" is where the next months of development will be spent, and titles will silently upgrade their status as syncs land — this table's Notes column is where those upgrades get recorded.

## Xbox Series X Versus a PC for PS5 Emulation

A fair question the Xbox experiment raises: if the console is basically a fixed-spec x86 PC, why not skip the desktop entirely? The honest comparison has edges on both sides. The Xbox wins on consistency — every unit is identical, thermals are solved, and results verified on one console reproduce on all of them, which no PC configuration can promise. The desktop wins on everything else: hardware flexibility, the full keyboard of graphics options, day-one access to every Kyty milestone (the Xbox port receives progress on sync delay), and the entire surrounding tooling ecosystem that the PS5 Emulator for PC scene has built around testing, capturing and sharing results.

The practical read for most readers: treat the two tracks as one story with two viewpoints. The desktop is where you go to actually run PS5 software today — start with the [safe setup walkthrough](/guide/how-to-run-ps5-games-on-pc) if that is your goal. The Xbox track is where you watch the architecture prove itself somewhere it was never invited, and where each new row in the table above quietly raises the ceiling for both.
