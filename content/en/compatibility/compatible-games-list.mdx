This page links the current project trackers. **We have not independently tested these games and do not maintain a measured FPS database.** The previous version described unnamed game results without a supporting table; those claims have been removed. Source links reviewed on October 22, 2026.

## Find your game in the right tracker

| Project | Compatibility evidence | What to check |
| --- | --- | --- |
| KytyPS5 | [Community compatibility list](https://kytyps5.github.io/) linked by the [project README](https://github.com/KytyPS5/KytyPS5#current-status) | Exact title, tested build, reached stage, remaining issues and hardware |
| AnyPS5 | [Per-game blocker map](https://alxcbtw.github.io/anyps5-roadmap/) linked by the [project README](https://github.com/boykopovar/AnyPS5#compatibility) | Per-title blockers and the underlying test report; a resolved blocker alone does not prove playability |

KytyPS5 and AnyPS5 use different approaches. Do not transfer a result from one project to the other. The older [InoriRus/Kyty repository](https://github.com/InoriRus/Kyty) is also distinct from KytyPS5; check the repository name before comparing reports.

## What a useful result contains

1. Search for the exact game title and edition. Match the game's region or title ID if the report provides it.
2. Record the emulator or relinker build and the test date. Results can regress as well as improve.
3. Separate a boot screen, menu, in-game scene and completed playthrough. A screenshot alone does not show completion.
4. Read the operating system, CPU, GPU, driver and settings. An FPS number without this context is not a hardware recommendation.
5. Open the linked report and check unresolved crashes, graphics, audio and saves before planning a playthrough.

## Record your comparison

| Field | Record from the original report |
| --- | --- |
| Game and title ID | Exact title and edition |
| Project and build | Repository plus version or commit |
| Test date and link | Original report, not a reposted screenshot |
| Hardware and settings | CPU, GPU, OS, drivers, resolution |
| Stage reached | Boot, menu, in-game or completed |
| Remaining problems | Crash locations, graphics, audio, saves |

If a title is absent, its status is **not established by that tracker**. Absence does not prove that the game cannot run. Consult the project's reporting instructions before contributing a result.

## Common questions

**Does this page confirm a 54 FPS result on an RTX 4060?** No. This wiki does not have a reproducible test record supporting its previous unnamed example.

**Is this a live list maintained by this wiki?** No. The links above lead to the projects' trackers. Their records can change after this page's review date.

**Where do I get AnyPS5?** Start with our [source-linked AnyPS5 guide](/emulators/anyps5-github) and the project's own documentation. This page distributes no game files.
